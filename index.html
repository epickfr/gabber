SETUP REQUIRED

This chat needs a free Supabase database before it can run. It takes about 5 minutes:

  1. Create a project at supabase.com.
  2. Open SQL Editor and run supabase/schema.sql.
  3. Go to Project Settings > API and copy the Project URL and the anon public key.
  4. Paste them into js/config.js locally, or set SUPABASE_URL and SUPABASE_ANON_KEY in Render.
  5. Reload this page.

The full walkthrough is in README.md. Messages are stored in Postgres, so they survive redeploys.
